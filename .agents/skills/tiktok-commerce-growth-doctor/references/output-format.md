# Output Format

Produce the report using this exact structure. Fill every section; if a section
genuinely doesn't apply, say so explicitly rather than omitting it. A complete worked
example is in `sample-diagnosis.md`.

```markdown
# Commerce Growth Diagnostic Report

## Executive Summary
[2–3 sentences: core finding, the constraint identified, and the recommended path.]

## Growth Stage
**Current Stage:** [Launch / Validation / Scaling / Expansion]
**Stage Characteristics:** [Key indicators that placed them in this stage]

## Growth Opportunity Assessment
**Assessment:** [Strong / Moderate / Limited]
**Reason:** [Supporting rationale]

## Adaptive Domain Weighting
| Domain | Weight | Rationale |
|--------|--------|-----------|
| Creative | XX% | [Why this weight for this stage/advertiser] |
| Campaign | XX% | [Rationale] |
| Catalog | XX% | [Rationale] |

## Domain Assessments

### Campaign
| Aspect | Status | Key Finding |
|--------|--------|-------------|
| Overall Health | [Status] | [Brief assessment] |
| Primary Concern | [Concern] | [Details] |

### Creative
| Aspect | Status | Key Finding |
|--------|--------|-------------|
| Overall Health | [Status] | [Brief assessment] |
| Primary Concern | [Concern] | [Details] |

### Catalog
| Aspect | Status | Key Finding |
|--------|--------|-------------|
| Overall Health | [Status] | [Brief assessment] |
| Growth Capacity | [Limited / Moderate / Strong] | [Reason] |
| Primary Concern | [Concern] | [Details] |

## Constraint Tree
[Observed Symptom]
  ↓
[Intermediate Cause]
  ↓
[Root Cause]
  ↓
[Growth Diagnosis]

## Growth Diagnosis: [Diagnosis Name]

### Root Cause Analysis

**Observed Signals:**
- [Signal 1]
- [Signal 2]
- [Signal 3]

**Evidence:**
- [Evidence point 1 with MCP source]
- [Evidence point 2 with MCP source]

**Alternative Hypotheses Considered:**
- [Hypothesis 1]: [Rejected because…]
- [Hypothesis 2]: [Rejected because…]

**Confidence:** [High / Medium / Low]

**Conclusion:** [Why this is blocking growth]

## Recommended Scaling Strategy
**Strategy:** [Creative Expansion First / Catalog Expansion First / Campaign Restructuring First / Scale Now / Scale Later]
**Rationale:** [Why this strategy now]

## If I Were Managing This Account
| Day | Action | Purpose |
|-----|--------|---------|
| Day 1 | [Immediate action] | [Why] |
| Day 2 | [Follow-up action] | [Why] |
| Day 5 | [Review point] | [What to check] |
| Day 7 | [Next phase] | [Expected outcome] |
| Day 14 | [Assessment point] | [Decision criteria] |

## Highest ROI Action
**Action:** [Single highest-impact action]
**Impact:** [High / Medium / Low]
**Effort:** [High / Medium / Low]
**Rationale:** [Why this action first]

## Impact vs Effort Matrix
| Action | Impact | Effort | Priority |
|--------|--------|--------|----------|
| [Action 1] | High | Low | P0 |
| [Action 2] | High | Medium | P1 |
| [Action 3] | Medium | Medium | P2 |

## Execution Readiness
| Action | Executable via MCP | Requires External Work | Notes |
|--------|--------------------|------------------------|-------|
| [Action 1] | Yes | No | Can execute immediately |
| [Action 2] | Partial | Yes | [What's needed] |
| [Action 3] | No | Yes | Route to [skill/team] |

## Specialized Skill Routing
1. **[Action 1]**: [Specific skill or method]
2. **[Action 2]**: [Specific skill or method]
3. **[Action 3]**: [Specific skill or method]

**Would you like me to proceed with [highest priority action]?**

## Follow-up Plan
- **48 hours:** [What to verify]
- **7 days:** [What to review]
- **14 days:** [When to re-run full diagnostic]
```
